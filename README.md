# Cabinet médical de Valentine

Site indépendant du cabinet médical de Valentine.

Initialisation : `database/bootstrap.sql` sur une base vide. Les recettes et modèles sont inclus ; stocks, caisse et prix démarrent à zéro ou non renseignés. Aucun utilisateur, message, commande ou historique d’un autre cabinet n’est inclus.

Supabase : `pmzghidkwdfbmqoigwre`. Les nouveaux comptes attendent une validation administrative.
